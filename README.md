# 혼합물 분리 공정 연구실

초등 6학년 과학 `[6과05-01]`, `[6과05-02]`, `[6과05-03]`을 연결한 가상 혼합물 분리 설계 앱입니다. 크기 선별선, 두 액체 관찰조, 소금 회수선, 통합 공정의 4개 미션에서 성질을 확인하고 공정을 설계·실행·성찰합니다.

분리 방법은 체로 분리·층 분리·거르기·가상 증발 4종이며, 준비 행동은 물 넣기·층 기다리기 2종입니다. 화면의 토큰과 결과는 실제 질량·순도·수율·시간·온도·부피를 측정하거나 보장하지 않는 모델입니다. 실제 활동은 교사의 안전 지도 아래 진행해야 합니다.

진행 기록은 학생 이름·실명·이메일 없이 브라우저 `localStorage`에만 저장됩니다. 키보드와 375px 화면, 스크린 리더 상태, `prefers-reduced-motion`을 지원합니다. 보고서의 업데이트 내역 버튼에서 변경 기록을 확인할 수 있습니다.

```bash
npm ci
npm run dev
npm test
npm run test:a11y
npm run test:e2e
npm run build
```
